## App Overview

**Luster** is built for auto detailing professionals, ceramic coating specialists, and detailing enthusiasts.

- **Offline-First & Private:** All records, invoices, photos, and vehicle profiles stay on-device using SwiftData. No accounts, no third-party tracking, no cloud telemetry.
- **Showcase Gallery:** Side-by-side interactive comparison slider for Before & After detailing photos.
- **Ceramic & Protection Lifespan Tracking:** Real-time wear-off progress gauges for coatings, sealants, and waxes.
- **Universal Design:** Custom tailored for both iOS (iPhone) and iPadOS with collapsible sidebar navigation and hardware keyboard shortcuts.
